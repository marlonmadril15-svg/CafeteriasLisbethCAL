# Cafetería El Buen Sabor

Proyecto Java Swing para administrar productos, pedidos y reportes de una cafetería. La aplicación organiza el código en paquetes `control`, `modelo`, `vista` y `util`, y conserva los datos en archivos de texto.

## Importar en Eclipse

1. Descarga el repositorio como ZIP desde el botón **Code**.
2. En Eclipse abre **File > Import > Existing Projects into Workspace**.
3. Selecciona la carpeta del proyecto y pulsa **Finish**.
4. En `src/cafelteriaiz/control`, abre `Main.java` y elige **Run As > Java Application**.

Los archivos `producto.txt` y `pedidos.txt` se encuentran en la carpeta raíz del proyecto.
